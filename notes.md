# Bioinformatics Learning Notes 👋

I am documenting my journey in learning bioinformatics tools and Linux commands for environmental microbiology research.

### 🐧 Linux/Bash Basics

#### Navigation & Directory Management
*   `pwd`: Print Working Directory - to see your current location.
*   `ls -l`: List Files - to view detailed information about files in a directory.
*   `mkdir`: Make Directory - to create a new folder for your research projects.
*   `cd`: Change Directory - to move into a specific folder.
*   `cd ..`: Move up one directory level.

#### File Creation & Manipulation
*   `touch`: Create an empty file (e.g., `touch notes.txt`).
*   `echo`: Display a line of text or write data into a file.
*   `cp`: Copy - to duplicate files or directories.
*   `mv`: Move/Rename - to move files to a different location or rename them.
*   `rm`: Remove - to delete a file.
*   `rm -r`: Recursive Remove - to delete a directory and all its contents.

#### Data Handling
*   `wget`: To download genomic data or files from the internet.
*   `cat`: To display the entire content of a file (e.g., viewing a FASTA file).
*   `grep`: To search for specific strings or patterns within a file.
